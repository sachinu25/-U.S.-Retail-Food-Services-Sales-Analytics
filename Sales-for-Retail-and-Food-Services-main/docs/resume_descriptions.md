## 1. ATS-Friendly Version (Universal)

> **U.S. Retail & Food Services Sales Analysis** | MySQL, SQL, Data Analytics
>
> - Analyzed **9,000+ monthly sales records** spanning 12 industries and 63 business categories across a 13-year period (2010–2022) using advanced SQL techniques
> - Developed **45+ production-grade SQL queries** utilizing CTEs, window functions (ROW_NUMBER, RANK, NTILE, LAG/LEAD), stored procedures, views, and performance indexes
> - Performed Pareto (80/20) analysis revealing that **top 20% of business categories** generated approximately **80% of total revenue**, enabling targeted resource allocation
> - Quantified **COVID-19 pandemic impact** across sectors, identifying that Restaurants & Bars declined **25-30%** while Grocery grew **8-12%** during 2020
> - Designed **6 reusable analytical views** and **5 parameterized stored procedures** for dashboard integration and on-demand executive reporting
> - Identified **seasonal revenue patterns** showing Q4 generates **28-32% of annual sales**, informing inventory and marketing budget allocation strategies

> **U.S. Retail Sales Analytics — End-to-End SQL Analysis** | MySQL 8.0, Power BI, Data Visualization

## 3. SQL Developer Version

> **Retail Sales Database — Advanced SQL Engineering** | MySQL 8.0, Window Functions, Stored Procedures, Query Optimization
>
> - Engineered a **MySQL 8.0 database** with optimized schema design (`DECIMAL(12,2)` for financial precision, `TINYINT` for space efficiency) and **10 strategic indexes** including composite and covering indexes
> - Authored **45+ analytical SQL queries** demonstrating mastery of CTEs, self-joins, correlated subqueries, CASE WHEN pivots, and conditional aggregation
> - Implemented all **12 major window functions**: `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `NTILE()`, `LAG()`, `LEAD()`, `FIRST_VALUE()`, `LAST_VALUE()`, running sums, moving averages, and window aggregates
> - Created **6 analytical views** (`v_kpi_dashboard`, `v_yoy_growth`, `v_seasonal_patterns`, etc.) to abstract complex query logic for dashboard consumption
> - Developed **5 parameterized stored procedures** (`sp_get_industry_report`, `sp_executive_dashboard`, etc.) enabling dynamic reporting without SQL modification
> - Applied **query optimization techniques** including covering indexes, proper NULL handling (`NULLIF`, `COALESCE`), and `EXPLAIN` analysis for performance tuning
